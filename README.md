# Vants — Soporte y Documentación

**Vants** es una extensión de GitHub Copilot Chat que lleva tu agente de IA a tu editor: gestiona issues, consulta proyectos y dispara automatizaciones de n8n usando lenguaje natural, en español o inglés.

## ¿Qué puedes hacer con Vants?

- Crear, actualizar y hacer triaje de issues desde Copilot Chat
- Consultar el estado de proyectos y generar resúmenes
- Ejecutar workflows de automatización alojados en n8n (alertas, informes, monitoreo)
- Trabajar en español o inglés

## ¿Cómo funciona?

Vants se conecta a un servidor MCP alojado en n8n. Cada petición se autentica con un token Bearer y se ejecuta contra los workflows que el propietario habilitó. No almacenamos código ni datos de los usuarios en servidores de terceros.
